# Roadmap

## Public Beta UX

- First-run setup for Managed Flow AI, permissions, privacy, and the first session.
- Friendly browser-preview mode for layout work outside Electron.
- Status center for capture, observation, planner, permissions, managed AI, and
  privacy state.
- Detail-panel corrections for titles, categories, notes, and feedback.
- Context-aware chat prompts and citation chips back to worklog blocks.

## Quality

- Expand planner benchmark cases for meetings, research/coding switches, brief
  lookups, and over-merge failures.
- Add demo event logs that let contributors open a rich UI without granting
  local capture permissions.
- Add visual regression screenshots for Today, Calendar, Chat, Insights,
  Settings, onboarding, and the detail panel.

## Later Data Controls

- Export/import event logs.
- Delete all local data with explicit confirmation.
- Optional screenshot preview viewer with privacy review.
