# Demo Data

Flow includes a small redacted demo event log at:

```text
benchmarks/demo-worklog/event-log.json
```

It contains planner snapshots only, so contributors can inspect Today,
Calendar, Insights, Chat prompts, and the detail panel without running native
capture.

To try it, copy the file into a disposable Flow data directory as
`event-log.json`, then launch Electron. Do not overwrite a real personal event
log unless you have backed it up.
